# Famulor MCP Server

AI voice agent platform with a full public tool catalog covering assistants,
cross-channel history, calls, campaigns, contacts, knowledge, messaging,
automations, dashboards, and workspace settings.

- Remote endpoint: `https://app.famulor.io/mcp` (streamable HTTP, OAuth 2.1 + PKCE)
- Docs: https://docs.famulor.io
- Setup guide: https://www.famulor.io/feature/mcp-connector
- Source: https://github.com/bekservice/Famulor-MCP
- Get an API key: https://app.famulor.io → API Keys
